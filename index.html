15. Common Misconceptions — These Are PAID ONLY

GPT-4o, Claude, Perplexity, Midjourney do NOT have real free tiers
▸
OpenAI GPT-4o / GPT-5 API
❌ NO free tier. Requires a valid billing method before any key works. Small unpublished trial credits expire, then payment is mandatory.
✅ Workaround: Use Puter.js or community proxies (Section 13) for free GPT-4o access
Anthropic Claude API
❌ NO free tier. Small unpublished trial credit on signup only; ongoing use requires payment. No renewing free quota exists.
✅ Workaround: Use Puter.js or community proxies (Section 13) for free Claude access
Perplexity API
❌ NO free tier. Pay-as-you-go only for the Agent API; no subscription-free option for developers.
✅ Workaround: Use Puter.js, which proxies free unlimited Perplexity-style search with zero key
Midjourney
❌ No public API at all on the free tier. Discord/web interface only; any usage requires an active paid subscription.
✅ Workaround: Use Pollinations AI, Stability AI, or Flux via Replicate instead
Runway Gen-4 (API access)
❌ Free credits (125) are one-time only, not renewing. Free plan output is watermarked.
✅ Workaround: Use Pika Labs (renews monthly) or self-hosted LTX-Video/HunyuanVideo instead
Google Veo / Sora 2
❌ No public free-tier API access as of this writing; closed/limited access programs only.
✅ Workaround: Use open-weight video models (Wan, LTX-Video, CogVideoX) self-hosted instead
